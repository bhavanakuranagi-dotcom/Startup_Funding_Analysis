# 🚀 Startup Funding Analysis 

A complete **Data Analyst Portfolio Project** that analyzes startup funding trends using **SQL, Excel, Python, Power BI, Machine Learning, and HTML**. This project demonstrates the complete data analysis workflow—from data cleaning to interactive dashboard creation and basic predictive modeling.

---

# 📌 Project Overview

This project explores startup funding data to identify:

- Funding trends over time
- Top funded startups
- Leading cities for startup investments
- Industry-wise funding distribution
- Investment type analysis
- Investor insights
- Funding prediction using Machine Learning
